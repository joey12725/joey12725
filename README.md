## Hey, I'm Joey. I build agents that build software.

### 📄 **[resume.joeyhersh.com](https://resume.joeyhersh.com)** · the full story, with receipts

Writing software is turning into directing it. I run twelve agent environments on my own hardware, all day and all night. They plan their own work on a project board, dispatch Claude Code, Codex, Gemini CLI and OpenCode workers, remember everything in pgvector, and talk to other people's agents. One 18-hour stretch logged 1,002 scheduled runs. Roughly 250B tokens have gone through my models so far ([how I count](https://resume.joeyhersh.com/evidence/)).

I founded [Guadalupe Automation](https://guadalupeautomation.com) to build agent systems for real businesses. By day I'm a data engineer at USAA, where I teach the team to build with agents.

**Where I think this is going**

- **Everyone gets a personal agent with a real memory**, and those agents deal with each other directly. → [peerpass](https://github.com/joey12725/peerpass), [inbox-recall](https://github.com/joey12725/inbox-recall)
- **The project board replaces the IDE.** People set goals and budgets. Agents plan, ship and report back. → [directive](https://github.com/joey12725/directive)
- **Code gets written at runtime**, on demand, from a sentence. → [splice](https://github.com/joey12725/splice)

### Agents

- **[directive](https://github.com/joey12725/directive)**: an AI engineering org on a real project board. A PM agent breaks goals into stories and spends your Claude, Codex and Gemini subscriptions like a budget.
- **[peerpass](https://github.com/joey12725/peerpass)**: lets other people's agents talk to yours over A2A, MCP, Slack, Discord, Telegram and Matrix with scoped, expiring passes.
- **[inbox-recall](https://github.com/joey12725/inbox-recall)**: gives your agent every conversation you've ever had (WhatsApp, iMessage, Signal, Instagram and more) as hybrid search over MCP.
- **[splice](https://github.com/joey12725/splice)**: describe a function in English, then call it like Python. It's generated once, cached and sandboxed.
- **[bookworm](https://github.com/joey12725/bookworm)**: turns your ebook library into a cited knowledge base and MCP server, all in one DuckDB file.
- **[focusgroup](https://github.com/joey12725/focusgroup)**: a focus group in your terminal. Synthetic personas across four model families, split tests and a verdict.
- **[cyrus-agent-framework](https://github.com/joey12725/cyrus-agent-framework)**: my 2024 multi-agent framework and the ancestor of directive.
